\begin{frame}
\frametitle{Question}
If the entries in each column of a square matrix \textbf{M} add up to 1, then an eigenvalue is
\begin{enumerate}
    \item 4
    \item 3
    \item 2
    \item 1
\end{enumerate}
\end{frame}


% Solution steps
\begin{frame}
\frametitle{Solution}
The question states that the sum of all elements in each column of the square matrix \textbf{M} is 1 then we have to find a number which is an eigen value of such matrix 
\end{frame}



\begin{frame}
\frametitle{Solution}
If we take a matrix \\
\begin{align}
    \textbf{v} = \begin{bmatrix}1,1,..,1\end{bmatrix}^T
\end{align}

Then , we can say that 
\begin{align}
    \textbf{M}\textbf{v} = \textbf{v}
\end{align}
\end{frame}

\begin{frame}
\frametitle{Solution}
From the above equation we can say that one of the eigen value for \textbf{M} is 1\\
Hence option 4 is true

\end{frame}
